# SYSTEM DEPENDENCIES — these are OS-level binaries, not Python packages, so
# `pip install -r requirements.txt` cannot install them. They must be
# installed once via your OS package manager before the video pipeline runs.
# This is the exact same tooling already used on this machine — install these
# and you get identical output, nothing swapped or approximated.
#
#   ffmpeg     — video/audio encode + compose (video_pipeline_local.py, video_composer.py)
#   ffprobe    — audio/video duration lookups (ships alongside ffmpeg)
#   pdftoppm   — PDF -> PNG slide rasterisation (part of poppler)
#   soffice    — PPTX -> PDF conversion (LibreOffice, ~500MB+ full app,
#                no pip/Python equivalent exists at the same fidelity)
#
# One-time install (pick your OS):
#   macOS   :  brew install ffmpeg poppler; brew install --cask libreoffice
#   Ubuntu  :  sudo apt install ffmpeg poppler-utils libreoffice
#   Windows :  choco install ffmpeg poppler libreoffice
#
# Verify all four are on PATH afterwards:
#   ffmpeg -version && ffprobe -version && pdftoppm -v && soffice --version
# ═══════════════════════════════════════════════════════════════════════════
